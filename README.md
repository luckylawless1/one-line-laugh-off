A make.fun bounty entry for [One-Line Laugh-Off](https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae): a program that writes exactly one funny line to `/output/entry.txt`.

## Run

```sh
node main.ts
```

It writes a single original one-line joke (94 characters, no trailing newline) to `/output/entry.txt`, well inside the gate's 1–200 character limit.
